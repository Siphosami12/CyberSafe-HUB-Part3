# CyberSafe Hub

### Your Safety, Our Priority

## 1. Project Overview

CyberSafe Hub is a website designed to promote cybersecurity awareness and online safety. It provides users with cybersecurity information, educational resources, cyber news, frequently asked questions, a gallery, contact information, and guidance on reporting cyber incidents.

## 2. Project Objectives

- Promote awareness of online threats and cybersecurity.
- Provide useful information about staying safe online.
- Help users access cybersecurity learning resources.
- Provide information about reporting cyber incidents.
- Create a responsive and user-friendly website.

## 3. Technologies Used

- HTML5 – website structure and content.
- CSS3 – styling, layout, and responsive design.
- JavaScript – website interactivity and form validation.
- Visual Studio Code – development environment.
- GitHub Pages – website hosting, if configured.

## 4. Website Pages

- Home
- About Us
- Courses
- Cyber News
- Gallery
- Frequently Asked Questions (FAQ)
- Contact Us
- Report an Incident

- `index.html` – main website entry page.
- `CSS/style.css` – website styling.

## 7. Testing

The website must be tested to confirm that:

- All navigation links open the correct pages.
- Images, CSS, and JavaScript files load correctly.
- Interactive elements work as intended.

- The website displays correctly on mobile devices and computers.
- HTML, CSS, and JavaScript errors are identified and corrected.
